# 07 — 管理员后台设计文档

## 7.1 设计目标

管理员后台用于平台运营和系统配置，必须做到：

1. 管理所有用户，但不查看用户密码、API Key 明文和 SMTP 密码明文
2. 配置全局 AI 模型和默认全局 API Key
3. 配置 SMTP 邮箱，用于注册验证、找回密码和欢迎邮件
4. 查看 AI 调用、邮件发送、用户管理等审计日志
5. 为后续学校/组织管理、套餐配额和移动端运营预留入口

## 7.2 管理员路由

```
/admin
├── /admin/users
├── /admin/users/[id]
├── /admin/ai-models
├── /admin/smtp
├── /admin/audit-logs
├── /admin/stats
└── /admin/settings
```

所有管理员页面必须：

- 需要登录
- 需要 `role = admin`
- API 错误展示 `requestId`
- 危险操作二次确认
- 修改全局配置后显示操作者、时间和影响范围

## 7.3 用户管理

### 列表字段

| 字段 | 说明 |
|------|------|
| 用户名/邮箱 | 基础身份 |
| 角色 | `student` / `admin` |
| 状态 | `pending_email` / `active` / `disabled` |
| 邮箱验证 | 已验证/未验证 |
| 注册时间 | 创建时间 |
| 最近登录 | 最近登录时间 |
| AI 调用次数 | 今日/累计 |

### 支持操作

| 操作 | 规则 |
|------|------|
| 新增用户 | 填写邮箱、姓名、初始密码、角色和状态 |
| 启用/禁用用户 | 禁用后用户不能登录和调用 API |
| 修改角色 | 至少保留一个管理员 |
| 修改状态 | 列表内直接选择中文状态后保存 |
| 删除用户 | 软删除并撤销旧会话，不能删除当前登录管理员 |
| 重置密码 | 管理员设置新密码，旧会话立即失效 |
| 重发验证邮件 | 仅未验证用户可用 |
| 撤销登录会话 | 使用户重新登录 |
| 查看用户 AI 配置摘要 | 只显示掩码和状态，不显示 Key 明文 |
| 查看用户流程统计 | 展示数量和时间，不默认展示隐私内容 |

## 7.4 全局 AI 模型管理

管理员可创建多个全局模型：

| 字段 | 说明 |
|------|------|
| 名称 | 如 `DeepSeek Chat - 全局默认` |
| 模型服务商 | 界面展示中文选项，接口使用 `deepseek` / `openai` / `zhipu` / `alibaba` / `moonshot` / `custom` |
| 接口地址 | OpenAI 兼容地址 |
| 模型 ID | 服务商模型 ID |
| 密钥 | 保存时加密，展示掩码 |
| 默认参数 | temperature, maxTokens |
| 是否启用 | 停用后不可被用户 fallback |
| 是否默认 | 全平台默认模型 |

界面必须避免展示「前端/后端」等工程视角说明；密钥相关文案统一面向用户说明为
「安全保存、仅展示掩码和连接状态」。
管理员选择常见模型服务商后，表单自动填入默认接口地址；如需使用代理、海外地域或私有兼容服务，可继续手动编辑。
所有全局模型配置字段必须提供输入示例和说明，尤其是接口地址、模型 ID 和密钥字段，避免管理员把服务商地址、模型标识和密钥混填。

### 策略设置

| 策略 | 说明 |
|------|------|
| 允许用户自定义模型 | 关闭后用户只能用全局模型 |
| 允许全局模型兜底 | 用户未配置模型时使用全局模型 |
| 全局模型每日配额 | 控制平台成本 |
| 模型测试通过才能启用 | 防止保存错误配置 |

## 7.5 SMTP 管理

SMTP 页面详见 `08_MAIL_SMTP_DESIGN.md`，管理员后台只负责 UI 入口和审计。

必须支持：

- 保存 SMTP 配置
- 发送测试邮件
- 查看最近测试结果
- 开关注册验证、欢迎邮件和找回密码邮件
- 邮件模板预览

SMTP 配置表单必须使用中文字段名，并为主机、端口、登录账号、密码、发件人和测试邮箱提供示例值与输入说明。

## 7.6 审计日志

### 审计范围

| 类型 | 示例 |
|------|------|
| 用户管理 | 新增用户、禁用用户、删除用户、修改角色、撤销会话 |
| 全局模型 | 新增/修改/删除模型、更新 API Key、设置默认 |
| SMTP | 修改 SMTP、测试邮件 |
| 登录安全 | 管理员登录、失败登录 |
| 系统设置 | 修改配额、修改邮箱验证策略 |

### 日志字段

- 操作人
- 操作类型
- 目标类型和目标 ID
- 操作前后摘要
- IP 和 User Agent
- 时间

审计日志禁止写入：

- API Key 明文
- SMTP 密码明文
- 用户密码或重置 Token

## 7.7 平台统计

管理员首页建议展示：

| 指标 | 说明 |
|------|------|
| 今日注册 | 新用户数 |
| 邮箱验证率 | 已验证 / 注册 |
| 今日 AI 调用 | 总调用次数 |
| AI 成功率 | 成功 / 总调用 |
| 平均 AI 延迟 | P50/P95 |
| 全局模型成本估算 | 基于 Token 用量 |
| 邮件发送成功率 | sent / queued |
