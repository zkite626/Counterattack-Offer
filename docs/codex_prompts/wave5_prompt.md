## Wave 5 任务

### 任务 5.1：首页 Hero 区

创建/更新 `src/app/page.tsx`：

Hero 区设计：
- 全屏高度，蓝紫渐变背景 + 微妙动态粒子/光效（纯CSS实现）
- 中心大标题："逆袭Offer" （Outfit 字体，大号，白色）
- 副标题："面向低经验大学生的 AI 求职突围智能体"
- 核心文案："不是每个大学生都有耀眼实习，但每段真实经历都可能藏着岗位价值。"
- 两个按钮：
  - "开始我的求职突围" → /login（主按钮，白色背景+紫色文字）
  - "一键体验 Demo" → Demo 模式（透明边框按钮）
- 向下滚动提示箭头动画

### 任务 5.2：痛点区

展示低经验学生的 6 个核心痛点：
- 卡片网格（3×2 桌面 / 2×3 平板 / 1×6 手机）
- 每张卡片：Emoji 图标 + 痛点标题 + 描述
- 卡片悬停效果（上浮 + 阴影）
- 入场动画（Intersection Observer 触发 slideUp, stagger 延迟）

痛点列表：
1. 🎯 方向不清晰 — 不知道能投什么岗位
2. 📄 经历空白 — 简历空、没有亮点
3. 🔍 盲目海投 — 不会匹配岗位
4. ✏️ 表达薄弱 — 简历写成流水账
5. 😰 害怕面试 — 不知道会被问什么
6. 📈 不知道怎么提升 — 能力差距大

### 任务 5.3：解决方案区

展示"六步求职突围闭环"：
- 步骤流图示（水平或之字形）
- 每步：图标 + 标题 + 一句话描述
- 步骤间有连接线/箭头
- 滚动入场动画

步骤：
1. AI 求职画像 → 2. 经历能力转译 → 3. 岗位 JD 解析 → 4. 人岗匹配雷达 → 5. 可信简历优化 → 6. 面试追问 + 能力计划

### 任务 5.4：核心功能区

6 个功能卡片，glass 效果：
- 每张：图标 + 标题 + 功能描述 + "了解更多" 链接
- 悬停效果（渐变边框）

### 任务 5.5：CTA 底部区

- 深色背景 + 渐变文字
- "让 AI 帮你发现经历中的岗位价值"
- "立即开始" 按钮
- 下方：产品特点 badges（真实经历 | 可信优化 | 完整闭环）

### 任务 5.6：一键 Demo 模式

实现 Demo 模式功能：
- 首页点击"一键体验 Demo" → 自动创建临时账户/自动登录
- 自动填充李同学案例
- 展示提示："正在使用 Demo 模式，数据为模拟案例"
- 顶部 Banner 提示 Demo 模式

### 任务 5.7：微动画打磨

为所有功能页面添加：
- 卡片进入视口时 slideUp 动画（stagger 延迟）
- 分数 ScoreRing 从 0 递增到目标值的动画
- ProgressBar 从 0 到目标值的动画
- 页面切换 fadeIn 过渡
- 按钮 hover 微上浮 + glow
- Tag 出现时 scaleIn
- 骨架屏 shimmer 动画

使用 Intersection Observer API + CSS @keyframes 实现，不使用动画库。

### 任务 5.8：响应式全面检查

检查所有页面在以下断点的显示：
- 375px（iPhone SE）
- 390px（iPhone 14）
- 768px（iPad）
- 1024px（小笔记本）
- 1280px（桌面）

修复发现的布局问题。
