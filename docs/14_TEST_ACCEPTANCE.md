| 测试项 | 验收标准 |
|--------|----------|
| OPTIONS 预检 | 返回允许的 Origin、Methods、Headers |
| credentials | Web fetch `credentials: include` 可携带 Cookie |
| SameSite | 生产环境 Refresh Cookie 使用 `SameSite=None; Secure` |
| Origin 拒绝 | 非白名单 Origin 被拒绝 |
| 移动端 | Bearer Token 请求不依赖 Cookie |
