# 00 — 项目总览

## 0.1 项目名称

**逆袭Offer：面向低经验大学生的 AI 求职突围智能体**

英文标识：`counterattack-offer`

## 0.2 项目定位

本项目是一个面向低经验大学生的 AI 求职陪跑 Web MVP，聚焦"实习少、项目少、方向不清晰、不会包装简历、不会准备面试"的大学生群体。

通过 AI 完成从个人经历挖掘、能力画像生成、岗位匹配分析、简历可信优化、面试追问训练到能力补齐计划的完整求职闭环。

**核心差异化**：不是通用聊天机器人，也不是简历润色工具，而是围绕大学生求职全流程的场景化智能体。低经验大学生并非没有能力，而是缺少将真实经历转化为企业可识别岗位能力的工具。

## 0.3 技术栈选型

| 层级 | 技术选择 | 说明 |
|------|----------|------|
| 框架 | Next.js 16 (App Router) | 全栈框架，前后端一体 |
| 语言 | TypeScript | 全栈类型安全 |
| 样式 | Vanilla CSS (CSS Variables) | 最大灵活性，Design Token 驱动 |
| 认证 | JWT (jose 库) | 轻量级，无数据库依赖 |
| AI 调用 | OpenAI 兼容协议 | 统一协议适配多模型 |
| 状态管理 | React Context + useReducer | 轻量级，无第三方依赖 |
| 数据持久化 | localStorage（MVP）→ 数据库（未来） | Repository Pattern 预留 |
| 部署 | Vercel / Docker | 开箱即用 |

## 0.4 核心理念

```
基于真实经历，挖掘岗位价值，而不是制造虚假优势。
```

### 关键原则

1. **不编造经历**：所有简历优化内容均基于学生真实输入
2. **不过度包装**：每条优化都保留来源经历和面试验证问题
3. **可验证性**：优化后的表达能经得起面试追问
4. **真实 AI 驱动**：对接真实大模型 API，非 Mock 数据

## 0.5 MVP 范围

### 必须实现

- JWT 认证登录/注册（无数据库，预留数据库接入）
- AI 模型管理（内置 + 自定义 OpenAI 兼容模型）
- 8 大核心功能模块（画像→转译→JD 解析→匹配→简历→面试→计划→报告）
- 响应式布局（手机、平板、桌面）
- 白天/黑夜模式
- 李同学 Demo 案例一键导入
- 精美视觉设计（年轻、专业、有希望感）
- 简历创建器（编辑+预览+多模板+PDF导出）

### 不包含（后续迭代）

- 数据库持久化
- 语音面试
- 高校后台
- 多用户管理

## 0.6 目标用户

### 一级目标用户

低经验大学生：无大厂实习、项目少、简历空泛、面试表达弱、不清楚适合岗位的本科 / 专科毕业生。

### 二级目标用户

高校就业指导老师、辅导员、校园招聘服务平台。

当前 MVP 仅服务学生端。

## 0.7 产品核心闭环

```
学生输入基础信息与经历
        ↓
AI 生成低经验求职画像
        ↓
AI 挖掘经历中的隐藏能力
        ↓
输入目标岗位 JD
        ↓
AI 解析岗位能力要求
        ↓
生成学生-岗位匹配报告
        ↓
输出简历可信优化建议
        ↓
生成面试问题与追问链
        ↓
生成能力补齐计划
        ↓
形成求职行动清单
```

## 0.8 视觉风格关键词

- 年轻、温暖、专业、有希望感、不焦虑、不夸张
- 主色：蓝紫渐变 / 科技蓝 / 青绿色
- 背景：深浅双色卡片式
- 图形：雷达图、进度条、标签云、步骤流
- 情绪：从"迷茫"到"清晰"的转变
